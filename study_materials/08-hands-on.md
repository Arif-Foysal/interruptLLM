# Module 08 — Hands-On

> This module connects theory to practice. You will walk through the codebase, run experiments, and recreate plots.

## Why this module matters

Reading about a system is different from running it. This module helps you see how the paper's numbers are produced and gives you a starting point for your own experiments.

## Notes in this module

1. [[01-codebase-walkthrough]] — Project structure, key files, data flow
2. [[02-running-experiments]] — Install dependencies, run local multi-run, run on Kaggle
3. [[03-plotting-and-analysis]] — Load JSON results, recreate figures, ask questions

## What you will do

- Set up the Python environment.
- Run the local multi-run script.
- Inspect result JSON files.
- Plot P0 P99 vs. load factor.
- Compare your results to the paper.

## Check your understanding

- [ ] I can install the project dependencies.
- [ ] I can run `run_local_multirun.py`.
- [ ] I can load and plot results.
- [ ] I can explain why my results might differ slightly from the paper.

## Time estimate

- 3–5 hours depending on your machine
- Longer if running on Kaggle

## Prerequisites

Before this module, complete [[07-reading-the-paper]] so you know what the code is trying to reproduce.
